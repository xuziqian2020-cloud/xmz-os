# 知识库导入与经验库停用设计

## 目标

停用与知识库重复的经验库入口；让知识库可导入整个文件夹，并使多文件或文件夹导入严格按文件建立知识记录。

## 范围

- 从主菜单、项目详情和项目模块配置中移除经验库。
- 旧的经验库页面地址分别重定向到全局知识库和对应项目的知识库，避免旧链接失效。
- 知识库导入区保留单文件导入到表单的行为。
- 多文件或文件夹导入不读取标题、分类、项目、标签或内容表单值；每个文件独立创建一条知识库记录。
- 批量导入的记录固定为：标题为文件名，分类为技术文档，项目为空，内容为提取结果，来源为文件在所选目录中的相对路径（非目录时为文件名）。
- Markdown、TXT、JSON、CSV 和日志文件改为在应用内读取文本并用等宽文本区域显示，不再交给白色 iframe 渲染。
- 文件管理按上传时的顶层目录分组；每个文件夹提供整组选中和整夹删除，删除通过单次批量接口完成。

## 数据流

浏览器选择多个文件或目录后，页面逐个调用现有文档提取接口。每次成功提取后，根据文件和提取结果构造固定的导入负载并请求现有知识库创建接口。单文件仍只回填编辑表单，只有用户点击创建时才保存。

## 错误处理与验证

批量导入继续完成其余文件，并汇总前几条错误。测试覆盖导入负载的固定字段、目录相对路径、菜单和项目模块不再暴露经验库、旧路由跳转、文本预览和整夹删除。最后运行全部测试、生产构建和浏览器界面检查。
